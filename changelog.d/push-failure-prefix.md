- **A push that fails on an exception, such as a path whose tree cannot be read, says `push failed:` once, where it said it twice.** `Nix.Push.pushPaths` put the prefix on an exception's message, and `nova-nix push` put it on every failure it was given, so such a failure read `push failed: push failed: ...`. `pushPaths` now reports an exception as it reports its other failures, unprefixed.

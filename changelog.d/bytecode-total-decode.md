- **Evaluating bytecode that holds a tag the compiler never writes, an unknown opcode or an unknown operator, formals, capture or binding tag, fails the evaluation with an error that names the tag, such as `corrupt bytecode: unknown binary operator tag 200`, where five of those cases stopped the program with a Haskell `error`.** Such a tag reaches the evaluator only from a corrupt bytecode store or from code built with `Nix.Eval.CBytecode.cbcEmit` rather than by the compiler. The store hands each tag back as a whole byte or word, so no type on the decoding side can rule one out, and each decoder answers a tag outside the set the compiler writes as a failure instead. The error is an evaluation error, which `builtins.tryEval` does not catch, and the one for an unknown opcode, which read `evalBytecode: unknown opcode`, names the opcode too.
- **Library API:** `Nix.Eval.Compile.decodeBcFormals` answers a `Maybe EvalFormals`, `decodeBcCaptureInfo` an `Either Word32 CaptureInfo` and `decodeBcBindings` an `Either Word32 [BcBinding]`, the `Left` holding the unknown tag, where each answered the decoded value alone. `Nix.Eval.Compile` exports each operator's tag pair, `encodeUnaryOp` with `decodeUnaryOp :: Word8 -> Maybe UnaryOp` and `encodeBinaryOp` with `decodeBinaryOp :: Word8 -> Maybe BinaryOp`, and `Nix.Expr.Types.UnaryOp` and `BinaryOp` derive `Bounded` and `Enum`.

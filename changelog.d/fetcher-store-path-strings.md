- **`builtins.fetchurl` and `builtins.fetchTarball` return the fetched store path as a string carrying itself as context, and so does the `outPath` of what `builtins.fetchGit` returns, as upstream's do.** Each returned a path value, so `builtins.typeOf` gave `"path"` where upstream gives `"string"`, the result printed unquoted, and `+`, `toString` and `builtins.isPath` treated it as a path. Upstream sets a fetcher's result with `allowAndSetStorePathString` (fetchTree.cc:526 at 2.24.9, :508 at 2.34.9) and fetchGit's `outPath` with `mkStorePathString` (:30 at 2.24.9, :33 at 2.34.9), a string whose context is the store path itself, so naming it in a derivation depends on that path rather than copying it to the store again as a path value would be.

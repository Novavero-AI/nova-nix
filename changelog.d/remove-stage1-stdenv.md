- **Nothing in `pkgs/windows` downloads a prebuilt compiler or shell: `stage1Stdenv`, the stdenv on MSYS2's bash and MinGW-w64's GCC, is removed with the 39 MSYS2 and MinGW-w64 binary packages it was made of, and the set's stdenv, the stage-2 one, takes its shell, tools and toolchain from the seed ladder, which builds them from stage0-pe32's seed.** The stage-2 stdenv builds every package the stage-1 one built, so nothing in the set used the stage-1 one. The packages were pinned by SHA-256 to repo.msys2.org, which drops old versions, and `pkgs/windows/sources.nix`, from which CI publishes every source the set fetches to the public cache, no longer lists them. `builtin:unpack` no longer extracts `.tar.zst` archives or skips the files at an archive's root whose names begin with a dot, pacman's `.PKGINFO` and `.MTREE` among them, which only those packages needed: a `.tar.zst` source fails with `unsupported archive format`, and a dot file at an archive's root is extracted like any other. It still extracts `.tar.gz` and plain `.tar` archives, and stage0-pe32's chain reads GitHub's `.tar.gz` archives through it.

- **Evaluation runs in a session that owns the C data layer, so no caller sets the data layer up or tears it down: `Nix.Eval.IO.withEvalSession` sets it up when no session holds it, makes the session's state, and tears it down as the outermost session ends, on an exception too.** A library caller had to wrap evaluation in `bracket_ arenaInit arenaDestroy`, and leaving that out raised `ArenaNotInitialized` at the first C call. A session now owns the window: a nested session shares the arena of the one around it and forgets the roots it registered as it ends, so what a collector over the C data layer keeps alive is what the open sessions hold. `nova-nix build` ends its evaluation's session before it builds, so the evaluation's memory is freed before the build starts.
- **Library API:** `Nix.Eval.IO` exports `SessionSettings`, `withEvalSession`, `nixPathSearchPath` and `evalSearchPath`, and no longer exports `newEvalState`; `newEvalStateWith` makes a state in the session already open. `Nix.Eval.Arena` is no longer exposed, so `arenaInit` and `arenaDestroy` leave the public API; `CStatusError` and `arenaLive` are in `Nix.Eval.CStatus`. `ArenaNotInitialized` names `withEvalSession` in its message.

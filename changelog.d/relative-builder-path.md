- **On Windows a builder named relative to the working directory, such as `./tools/bash` or `tools/bash`, puts none of its directories on the build's `PATH`, as a bare name or `./bash` already put none.** The build's working directory is its build directory, so `./tools` on `PATH` would let a file the build writes there resolve ahead of every tool; only a builder whose directory is absolute, or rooted on the working directory's drive, adds its directory and that directory's sibling `usr\bin`.

- **`builtin:unpack` reads `.tar.gz` archives, the format GitHub serves a commit's tree in.** It read `.tar.zst` and plain `.tar`, which covers MSYS2's packages, and GitHub's archive endpoint offers only gzip and zip, so a repository pinned at a commit could not be unpacked before a tool to unpack it existed. The decompressor is still chosen by the archive's name. A corrupt or truncated stream fails the build with the decoder's message, as a corrupt zstd frame does. The pax global header `git archive` writes first, which carries the commit id, is skipped like any other. The library depends on zlib >= 0.7, the first release whose `Codec.Compression.GZip` exports the error a bad stream throws; it was already in the build through http-client.

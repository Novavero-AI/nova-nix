- **`pkgs/windows/unused-prebuilt.json` lists each prebuilt file in a source archive the stdenv's closure unpacks, with why no build uses it, and every build that unpacks one of those archives removes its listed files first.** GNU's GCC and binutils releases carry zlib's MASM objects, libgo's test data and binutils' test-suite inputs, and stage0-pe32's tree carries the original hex0, whose DOS header its development generators copy. GNU publishes no release archive without them and stage0-pe32's tree stays as it is, so what can hold is that no build reaches them. The seed stdenv's unpack phase, which the package set's stdenv runs too, removes the files a derivation's `unusedPrebuilt` names, and both stdenvs' `mkDerivation` set it from the list for `src`. A listed file the archive does not hold fails the build, so the list cannot go stale unnoticed. The Stdenv ladder job runs `nova-nix trust --json` over GNU Hello and fails on any input a build runs that is not the seed or a reproduction of it, any prebuilt file the list does not name, and any file the list names that the report does not find. Every rung's store path changes.

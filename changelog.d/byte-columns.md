- **A position's column counts bytes, as upstream's does, so `builtins.unsafeGetAttrPos`, `__curPos` and a syntax error give upstream's column on a line with non-ASCII text before the position, where a character UTF-8 spells in several bytes took one column.** Upstream's lexer advances its location by the length in bytes of everything it reads (`adjustLoc`, lexer-helpers.cc, run for every match by `YY_USER_ACTION`, lexer.l), a position is the byte offset where its token begins (`ParserState::at`, parser-state.hh), and the position table makes its column one past that offset's distance from the start of its line (`PosTable::operator[]`, nixexpr.cc at 2.24.9, pos-table.cc at 2.36.0). The lexer here now counts the same way, so each position after a U+00E9 on its line is a column further than it was, for the character's second byte. A UTF-16 source's syntax error counts the bytes of its UTF-8, which is what the lexer reads.

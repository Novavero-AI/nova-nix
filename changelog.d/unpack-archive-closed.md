- **builtin:unpack closes an archive once it has read it, where an unpack stopped partway through, by its budget or a refused entry, left the archive open until a garbage collection.** The archive was read lazily, so its handle stayed open until the rest of it was read, which an unpack that stops never does, or until a collection finalized it; on Windows an open file cannot be deleted, so the archive's store path could not be removed in the meantime by the process that unpacked it. The archive is now read whole and its file closed before it is decompressed and decoded.

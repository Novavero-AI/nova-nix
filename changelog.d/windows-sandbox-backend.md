- **`nova-nix-sandbox` builds on Windows, with a backend that runs a builder as the build slot's account whose token it is handed: on the window station of that token's logon, with its image opened as the slot, attached to a pseudoconsole the helper owns, in a job that caps each process's memory and lets none of them break away, and with every process of the slot's account ended before the build and after it. Windows builds do not run through it yet, and run as before.** Upstream's builds run as `nixbld` users, and upstream ends every process of its build user before and after each build. On Windows a build account's token is held by the service that logs each slot on and starts the helper, which hands it one slot's token as a handle the plan names, with the slot's SID, and the helper refuses a token that is not a primary token of that account. The builder starts with no window station named, which puts it on the station Windows makes for the slot's logon, since a service running as a virtual account cannot make one and its own is not the slot's to open. CreateProcessAsUserW opens a builder's image with its caller's access, so the helper starts the builder impersonating the slot, and refuses a builder the slot may not read. A process started with a console of its own, as libiberty starts gcc's subprograms when gcc has none, fails to start under a build account's token, where one sharing its parent's console starts, so the builder is attached to a pseudoconsole the helper owns and drains; the build log stays the builder's standard output and error, and its standard input is NUL. The builder starts suspended and joins the build's job before it runs; the job kills its processes when the helper's handle to it closes, however the helper ends, ends a process at an unhandled exception at once, and nests in the process library's job. A process a build has WMI start runs outside the job and outlives it, holding what it copied from the build, the build log among them, so the helper ends every process running as the slot's account before the builder starts and once the job holds no process, listing them again until a listing finds none; a sweep that fails before the build is reported on the status channel, and one that fails after it is said in the build log and fails the build. The helper exits with the builder's exit code once the job holds no process and the sweep is done, ends the job when its lifeline closes, says in the build log which process the memory cap stopped, and reports a step that fails before the builder starts on its status channel, with the Win32 error of the call that failed. Its probe checks that it can enable `SeAssignPrimaryTokenPrivilege` and `SeIncreaseQuotaPrivilege`, which starting a process as another account takes.
- **Library API:** `Nix.Builder.Sandbox` gains the helper's Windows plan (`WindowsPlan`, `renderWindowsPlan`) and its Windows steps (`WindowsStage`, `windowsStageName`), and `ProbeStage` gains `ProbePrivileges`, which a match on every `ProbeStage` needs. `Nix.Store.Access` exports `sidText`, a `Sid`'s string form.

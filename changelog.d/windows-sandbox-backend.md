- **`nova-nix-sandbox` builds on Windows, with a backend that runs a builder as the build slot's account whose token it is handed: on a window station and desktop of the build's own, attached to a pseudoconsole the helper owns, in a job that caps each process's memory and lets none of them break away. Windows builds do not run through it yet, and run as before.** Upstream's builds run as `nixbld` users; on Windows a build account's token is held by the process that starts the helper, which hands it one slot's token as a handle the plan names, with the slot's SID, and the helper refuses a token that is not a primary token of that account. A process a service starts would start on the service's window station, which a slot's account cannot open, so the helper makes a window station and desktop for the build, granting its own user and the slot's account alone, and refuses a window station of that name that already exists, whose DACL another chose. A process started with a console of its own, as libiberty starts gcc's subprograms when gcc has none, fails to start under a build account's token, where one sharing its parent's console starts, so the builder is attached to a pseudoconsole the helper owns and drains; the build log stays the builder's standard output and error, and its standard input is NUL. The builder starts suspended and joins the build's job before it runs; the job kills its processes when the helper's handle to it closes, however the helper ends, ends a process at an unhandled exception at once, and nests in the process library's job. The helper exits with the builder's exit code once the job holds no process, ends the job when its lifeline closes, says in the build log which process the memory cap stopped, and reports a step that fails before the builder starts on its status channel, with the Win32 error of the call that failed. Its probe checks that it can enable `SeAssignPrimaryTokenPrivilege` and `SeIncreaseQuotaPrivilege`, which starting a process as another account takes.
- **Library API:** `Nix.Builder.Sandbox` gains the helper's Windows plan (`WindowsPlan`, `renderWindowsPlan`) and its Windows steps (`WindowsStage`, `windowsStageName`), and `ProbeStage` gains `ProbePrivileges`, which a match on every `ProbeStage` needs. `Nix.Store.Access` exports `sidText`, a `Sid`'s string form.

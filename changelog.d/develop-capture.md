- **Library API:** `Nix.Develop.Capture` makes the derivation upstream's `nix develop` builds to capture a target's build environment (`getDerivationEnvironment`, develop.cc at 2.35.4). `captureDerivation` refuses a builder whose base name is not `bash`, makes upstream's `get-env.sh` the builder's one argument and an input source, removes the checks on what the outputs refer to (under structured attributes, `outputChecks`, with `__json` written again as nlohmann's `dump()` writes it), names the capture `NAME-env`, and fills its outputs in input-addressed, so a fixed-output target's capture is input-addressed too. `getEnvScriptPath` gives the script's store path, `/nix/store/hyhh9rhzxhzmfspllmpf75xzkzns109r-get-env.sh`, since upstream stores the file after a newline its build puts in front of it; the file ships as `data/develop/get-env.sh`, upstream's 2.35.4 copy under its LGPL-2.1 license. `environmentOutput` picks the output the environment is read from, the first in name order that is a regular file of at least one byte.

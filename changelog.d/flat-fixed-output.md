- **An output under a flat fixed-output hash must be a regular file its owner may not execute, read without following a symlink, as upstream requires of every build's, and any other fails with upstream's `output path '<path>' should be a non-executable regular file since recursive hashing is not enabled (one of outputHashMode={flat,text} is true)`.** Upstream reads the output with `lstat` and refuses any other form in `registerOutputs` (local-derivation-goal.cc:2326 and :2501-2507 at 2.24.9). nova-nix refused only a directory, in words of its own, and followed a symlink: a symlink output was hashed as the file it named and registered as the symlink, and an executable file was registered `0555` under a hash that records no mode. The rule holds for every builder, a spawned one and `builtin:fetchurl` alike, and for the rebuild `nova-nix build --check` compares.
- **Library API:** `Nix.Store.Metadata` exports `isPlainFile`, whether a node is a regular file its owner may not execute.

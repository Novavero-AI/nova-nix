- **A failed `builtins.tryEval` returns a set of its own, so `nova-nix eval --strict` prints two failed results in full, where it printed the second as upstream's repeated marker.** Upstream's `prim_tryEval` builds the result's bindings on each call, a failed one included (primops.cc), and the printer marks a set as repeated only by identity, so `[ (builtins.tryEval (throw "a")) (builtins.tryEval (throw "b")) ]` prints `{ success = false; value = false; }` twice under both. Every failed `tryEval` here returned the same set.

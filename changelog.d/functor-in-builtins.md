- **A set with `__functor` is called as a function by every builtin that calls a function it was given, as upstream's `callFunction` calls one: the predicate of `filter`, `any`, `all` and `partition`, the comparator of `sort`, the function of `groupBy` and `foldl'`, `genericClosure`'s `operator`, and the filter of `builtins.path` and `builtins.filterSource`.** nova-nix applied the functor only where a call is written in source or deferred, as `map`'s are, and these builtins refused a functor with `attempt to call a set, which is not a function`. Upstream's `callFunction` (eval.cc, the same at 2.24.9, 2.34.9 and 2.36.0) applies `__functor` to the set and then to the argument wherever it is called.

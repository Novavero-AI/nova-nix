- **An imported file is evaluated once per evaluation whatever its value, as upstream caches every file: `import ./f.nix == import ./f.nix` is `true` for a file whose set holds a function, and a trace in it prints once, where a file whose value is a set of 1,000 or more attributes was evaluated again by every import.** Upstream's `evalFile` answers a later import of a file from `fileEvalCache`, which keeps every file's value (eval.cc:1052-1097 at 2.24.9). Leaving a large set out of the cache freed nothing, since a session's values are freed when the session ends. (#580)

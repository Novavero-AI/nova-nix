- **A string a builtin reads without context is refused naming its first context element as upstream 2.34.0 and later display one: a path by its store path, a derivation's outputs by its `.drv`'s store path and ` (deep)`, and one output by the `.drv`'s store path, `^` and the output's name.** Upstream builds the message from `NixStringContextElem::display` (eval.cc at 2.36.0), so `builtins.match`, `builtins.toFile`'s name, `builtins.compareVersions`, a derivation's name and a computed attribute name each say `(such as '/nix/store/...-a')`. nova-nix named the element by its encoding, as 2.24.9 did, which wrote a path by its base name and a derivation's outputs and one output as `=` and `!out!` prefixes.

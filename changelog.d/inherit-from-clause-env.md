- **The names an `inherit (from)` clause binds select from one environment holding the from-value, where each name had an environment of its own.** Upstream 2.24.9 makes one environment for the from-values of a binding set, in which each inherited name's select runs (`ExprAttrs::buildInheritFromEnv`, eval.cc:1179-1189); over the first 2,000 attributes of nixpkgs 24.11 nova-nix made 505,134 environments for `inherit (from)`, one per name (#529). The clause's from-value was already one thunk for all its names, so each name reads the same value it did. On a program evaluating `let inherit (s) p q r;` 100,000 times, `inherit (from)` makes 100,000 environments where it made 300,000. What any program evaluates to is unchanged.

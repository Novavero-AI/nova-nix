- **`builtins.toFile` refuses contents that refer to a derivation in upstream's words, naming the file and the reference: `files created by builtins.toFile may not reference derivations, but x references !out!...-d.drv`.** nova-nix refused them with `builtins.toFile: files created by toFile may not reference derivations`, naming neither. Upstream's `prim_toFile` (primops.cc, the same at 2.24.9, 2.34.9 and 2.36.0) names the first element of the contents' context that is no plain store path, in the order it keeps a context: a derivation's every output, `=` and its `.drv`, ahead of one output, `!out!` and its `.drv`; nova-nix names the same one.

- **A narinfo whose StorePath has the requested path's hash and another name is passed over, as upstream passes one over, where nova-nix took it for the requested path.** Upstream's `Store::queryPathInfo` (store-api.cc, the same at 2.24.9, 2.34.9 and 2.36.0) holds the path a narinfo names to the requested one by `goodStorePath`, which compares the name as well as the hash, and moves on to the next substituter when they differ; nova-nix compared the hash alone.

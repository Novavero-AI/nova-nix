- **The `derivation` wrapper names its values as upstream's does, so `({ }: null) (import ./f.nix)`, where `f.nix` is `{ zz = 1; shared = 2; }`, names `zz` as the unexpected argument, as upstream does, where it named `shared`.** A set holds its attributes in the order their names were interned, and upstream interns its wrapper's names as it starts, before any program's (primops/derivation.nix at 2.24.9). nova-nix's wrapper named four of its values `paths`, `entries`, `shared` and `entry`, which upstream's names `strict`, `outputsList`, `commonAttrs` and `x`, so compiling it interned those four after the first program's names and before every name a file imported later brings. It now uses upstream's names, which nova-nix interns as it starts too, so compiling it interns nothing. Its structure, and every position a program can read from it, is unchanged.

- **The census `NOVA_NIX_C_STATS` writes counts the environments and attribute sets by the construct or builtin that allocated them, and the environments by number and by size.** Over a nixpkgs slice environments took nearly five times upstream's bytes and attribute sets numbered 1.6 times upstream's (#529, #530), and the census gave each kind's bytes without saying which constructs allocated them, so nothing showed which to make smaller or stop allocating. Every environment and attribute set allocation now names its site: a call, a call with formals, a closure, a `let`, a `rec` set and what each captures, `inherit (from)`, `with`, a set literal, `//`, and each builtin that makes a set. With the variable set the allocators count each allocation under its site from the arena's start: environments with their slots and bytes and by slot count, which also gives the number of environments, and sets with their bytes and how many equal a set that already existed, an empty set or a `//` result with an empty operand, neither of which upstream allocates (`EvalState::allocBindings` in attr-set.cc and `ExprOpUpdate::eval` in eval.cc). Without the variable an allocation tests one flag and counts nothing. `profiling/bench.sh --memory` reports the figures, the environments' slots beside upstream's `envs.elements`.
- **Library API:** every constructor of an environment or attribute set takes, first, the `EnvSite` or `SetSite` (`Nix.Eval.AllocSite`, new) it allocates for: `attrSetFromMap`, `attrSetFromEntries`, `attrSetMapWithKey` and `attrSetRemoveKeys`, and in `Nix.Eval.CAttrSet` and `Nix.Eval.CEnv` `cattrsetNew`, `cattrsetUnion`, `cattrsetRemoveKeys` and `cenvPushWith`. `Nix.Eval.AllocSite` gives each site's name in the census (`envSiteName`, `setSiteName`) and its index in the C counts (`envSiteIndex`, `setSiteIndex`). `Nix.Eval.CStats` also has `countSites`, which turns counting by site on, `siteCounts`, which reads the `SiteCounts` (an `EnvSiteFigures` for each environment site, a `SetSiteFigures` for each set site, and the environments by `EnvSize`), `envSitesCounted` and `setSitesCounted`, and the census's `censusSites`. `attrSetUnionWith` and `pushWithScope`, which nothing called, are removed.

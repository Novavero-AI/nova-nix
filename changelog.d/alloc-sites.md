- **The census `NOVA_NIX_C_STATS` writes counts the environments and attribute sets by the construct or builtin that allocated them, and the environments by number and by size.** Over a nixpkgs slice environments take nearly five times upstream's bytes and attribute sets number 1.6 times upstream's (#529, #530), and the census gave each kind's bytes without saying which constructs allocated them, so nothing showed which to make smaller or stop allocating. Every environment and attribute set allocation now names its site: a call, a call with formals, a closure, a `let`, a `rec` set and what each captures, `inherit (from)`, `with`, the deferred applications of `map`, `genList`, `concatMap`, `mapAttrs` and `zipAttrsWith`, a set literal, `//`, and each builtin that makes a set. With the variable set the allocators count each allocation under its site from the arena's start: environments with their slots and bytes and by slot count, which also gives the number of environments, and sets with their bytes and how many equal a set that already existed, an empty set or a `//` result with an empty operand, neither of which upstream allocates (attr-set.cc:16-17 and eval.cc:1908-1909 at 2.24.9). Without the variable an allocation tests one flag and counts nothing. `profiling/bench.sh --memory` reports the figures, the environments' slots beside upstream's `envs.elements`.
- **Library API:** every constructor of an environment or attribute set takes, first, the `EnvSite` or `SetSite` (`Nix.Eval.AllocSite`) it allocates for: `attrSetFromMap`, `attrSetFromEntries`, `attrSetMapWithKey`, `attrSetRemoveKeys`, `newCEnv`, `newMinimalEnv`, `envFromSlots`, `buildCSlots`, `tieFrame`, `withScopesForCapture` and `deferApply`, and in `Nix.Eval.CAttrSet` and `Nix.Eval.CEnv` `cattrsetNew`, `cattrsetUnion`, `cattrsetRemoveKeys`, `cenvAllocSlots`, `cenvAllocWithScopes`, `cenvNew`, `cenvFromSlots`, `cenvPushWith` and `cenvNewMinimal`. `Nix.Eval.CStats` adds `countSites`, `siteCounts` and the census's `censusSites`. `attrSetUnionWith` and `pushWithScope`, which nothing called, are removed.

- **`builtins.partition` forces each element before it calls its function on it, as upstream's does, so `builtins.partition (x: true) [ (throw "e") ]` fails with `e`.** Upstream's `prim_partition` (primops.cc, the same at 2.24.9, 2.34.9 and 2.36.0) forces every element in list order as it partitions, where nova-nix passed each one unforced, so an element the function never looked at could hold a failure that never surfaced. `any`, `all`, `filter` and the other higher-order builtins still pass their elements unforced, as upstream's do.

- **Making an attribute set, a lambda, a builtin's partial application or a string with context outside an evaluation session raises `ArenaNotInitialized` naming its C entry point, as every other C data-layer allocation does, where it made an object the next session's end freed.** The arena's teardown frees these objects one by one from a record of each kind, so one made outside every session sat below every region the collector runs and was freed when the next session ended, under whoever still held it. The thunk arena, the env pages, the string arena, the symbol table and the bytecode store already refused outside a session, and a list through its items, which come from the env pages.
- **Library API:** a caller that makes these objects directly, through `Nix.Eval.CAttrSet`, `Nix.Eval.CLambda`, `Nix.Eval.CPrimop` or `Nix.Eval.CCtxStr`, does so inside `Nix.Eval.IO.withEvalSession`.

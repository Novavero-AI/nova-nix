- **Every value lives in the C data layer: a builtin and a builtin applied to some of its arguments are C values, so no value sits in GHC's heap behind a StablePtr, and the census follows the whole value graph in C.** A builtin value and a partial application were the last values a thunk held as a StablePtr to a Haskell value, so a collector in C could not reach the cells a partial application held. A builtin is now its index, inline in its cell, and a partial application is a C object holding the builtin's index and the cells of the arguments it has taken, as upstream's `tPrimOp` and `tPrimOpApp` hold a primop and the values applied to it (value.hh at 2.24.9). The builtin bound under its own name is one static cell per builtin, as upstream binds one value per primop (`EvalState::addPrimOp`, eval.cc), so it is the same value in every file and survives the arena's teardown. `match` and `split` hold their pattern as a string and compile it through the cache keyed by the pattern on each call, as upstream's `RegexCache` does (primops.cc:4187-4206), where a partial application held the compiled regex; the regex engine is unchanged. Applying a builtin now selects its implementation by its constructor rather than by comparing its name with each builtin's: on an Apple M2, best of three, two million saturated builtin calls take 1.40 s where they took 1.74 s, and 200,000 calls through a stored `builtins.elem` and a stored `builtins.match` take 0.47 s where they took 0.53 s. The census `nova-nix eval` writes under `NOVA_NIX_C_STATS` counts partial applications as a kind of their own (`primopapps.*`). What any program evaluates to is unchanged.
- **Library API:** `NixValue`'s `VBuiltin` holds a `Builtin` from the new `Nix.Eval.Builtin`, one constructor per builtin, where it held the builtin's name; `builtinName` and `builtinNamed` convert, and `builtinIndex` and `builtinAtIndex` give the index the C data layer holds. `VCompiledRegex` and `CompiledRegex` are removed. `Nix.Eval` exports `listedBuiltins`, the builtins `builtins` lists, where it exported `builtinNames` and `builtinRegistry`. `Nix.Eval.CPrimop` (new) binds the partial application object. `Nix.Eval.CThunk` loses `cthunkNewComputed` and `cthunkSetComputed`, which stored a StablePtr, and gains `cthunkPrimop`, a builtin's static cell, with `cthunkNewComputedPrimop`, `cthunkNewComputedPrimopApp`, `cthunkSetComputedPrimop`, `cthunkSetComputedPrimopApp`, `cthunkGetPrimop` and `cthunkGetPrimopApp`. `Nix.Eval.Types` exports `PrimopCell` and `primopCell`. `Nix.Eval.CStats.PerKind` has a `kindPrimopApps` field.

- **`NIX_CONFIG_HOME` holds the user's `nix.conf`, as upstream 2.36.0 reads it.** Upstream's `getConfigDir` returns `NIX_CONFIG_HOME` itself when the variable is set, the directory `nix.conf` sits in rather than one with a `nix` directory beneath it, and otherwise `nix` under the XDG config home (users.cc at 2.36.0); its user config files are that directory's `nix.conf` and then each `XDG_CONFIG_DIRS` entry's, unless `NIX_USER_CONF_FILES` names others. nova-nix read the XDG config home's file whatever `NIX_CONFIG_HOME` said. An empty `NIX_CONFIG_HOME` is set, as upstream reads it, and names `nix.conf` in the working directory.
- **Library API:** `ConfigLocations` has a field `clNixConfigHome`, `NIX_CONFIG_HOME`'s bytes when it is set; a record built with every field lists it.

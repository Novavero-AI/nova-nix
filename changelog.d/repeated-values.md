- **`nova-nix eval` prints a derivation and exits, with and without `--strict`, and `builtins.deepSeq` on one returns, where each ran without end: a set or list reached a second time prints as upstream's repeated marker, in the eval result and in error and trace messages.** A derivation's `all` and output attributes hold the derivation itself, and the deep force behind `--strict` and `builtins.deepSeq`, and both printers, followed them each time they were reached. Upstream's `forceValueDeep` enters each value once (eval.cc:2099-2131 at 2.24.9), `printAmbiguous`, which `nix-instantiate --eval` prints through, prints a set or list it has printed before as the marker (print-ambiguous.cc:38-66), and so does the printer behind error and trace messages, whose `trackRepeated` is on by default (print-options.hh:59, print.cc:330-446); the ones here now do the same. Each goes by identity, never by contents, so two equal sets made apart both print in full; here the identity is the C set, list or thunk cell the value lives in, which nothing frees before evaluation ends. The two printers differ where upstream's do. The result printer never marks an empty set or list, and takes a list of one or two elements as one per cell that holds it and a longer list as one however many cells hold it, since upstream keeps a short list's elements inside the value that holds the list and a longer one's in an array its copies share (value.hh:407-410). The message printer takes a list with elements as one per cell that holds it, whatever its length, and marks a second empty set, since upstream allocates a set built with room for no attributes as its one empty set (attr-set.cc:16-17); a set `removeAttrs` empties, an `intersectAttrs` of two sets with no name in common, or a set literal whose every name is a null `${...}`, is a set of its own upstream and the one empty set here. A traced list that holds itself prints one level deeper than upstream's before the marker: upstream's trace hands its printer the argument's own value (primops.cc:1018), and the printer here starts from a value with no cell. `--strict` forces the result in place and prints the result itself, where it printed a copy rebuilt while forcing, which held no set or list twice.

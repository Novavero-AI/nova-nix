- **A cache that fails now stops the build, as upstream's does, and `--fallback` or the `fallback` setting builds from source instead.** A failed substitution was treated like a path the cache lacks, so a 503 that outlived its retries, a NAR that did not verify, a compression it cannot decode or a narinfo that would not parse sent the build on from source, and with outputs tried before inputs one transient failure on a root started its whole input tree. Upstream tells the two apart (`substitution-goal.cc` and `derivation-goal.cc` at 2.24.9). A NAR a cache offers and fails to deliver, once every cache has been tried, fails the derivation with upstream's message, `some substitutes for the outputs of derivation '...' failed (usually happens due to networking issues); try '--fallback' to build derivation from source`, and exit status 1. The `.drv` is named under `/nix/store` wherever the store's files live, on Windows and under `--store` too, as upstream's `printStorePath` prints a relocated store's logical directory. A narinfo query that fails stops the build with that failure before a later cache is asked, as upstream rethrows it. Under `--fallback`, or `fallback = true` (alias `build-fallback`) in nix.conf, a failed query is reported and the next cache asked, and a failed substitute is reported and the derivation builds. A cache without the narinfo, a narinfo for another path or one no trusted key signed, and a NAR the cache answers 404 for are passed over as before, so what no cache holds still builds with no flag. Upstream also disables a failing cache for 60 seconds under `fallback`; here each path asks it again.
- **Library API:** In `Nix.Realise`, `seReferences` returns an `Offer`, `seFetch` a `FetchOutcome` and `substituteClosure` a `ClosureOutcome`, and `realise` takes a `Fallback` and returns `Either RealiseFailure ()`, which `realiseFailureMessage :: RealiseFailure -> Text` renders. `Nix.Builder.BuildConfig` gains `bcFallback`, and `substitutePaths` returns a `FetchOutcome`. `Nix.Substituter.queryReferencesWith` takes a `Fallback` and returns an `Offer`, `narInfoPreflight` is removed, and `NarInfoAnswer` and `judgeNarInfo` are added. `Nix.Config.NixConfig` gains `ncFallback`.

- **On Linux and macOS a file's executable flag in a NAR is the owner-execute bit of its mode, as upstream's dump reads it, where nova-nix asked whether it could execute the file.** Upstream's `PosixSourceAccessor` (posix-source-accessor.cc at 2.36.0) takes `st_mode & S_IXUSR`; nova-nix's `Nix.Store.ExecBit.isExecutable` answered from `access(2)`, which differs for a process running as root, which may execute a file any of whose execute bits is set, and for a file whose access control list refuses execution, so in those cases a path's NAR, and so its NAR hash and any path made from it, differed from upstream's. Windows, which keeps the flag in a stream of the file, is unchanged.

- **A Boolean setting given a value it cannot take is refused naming the setting, where it named the alias it was set through: `build-fallback = maybe` is refused as `Boolean setting 'fallback' has invalid value 'maybe'`, as upstream refuses it.** Upstream's `BaseSetting<bool>::parse` (config.cc at 2.24.9, configuration.cc at 2.36.0) throws with the setting's own name, which `Config::set` reaches through the alias's entry in the same table, and nova-nix's integer settings already named theirs that way. `fallback` is the only Boolean setting nova-nix reads that has an alias.

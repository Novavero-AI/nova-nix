- **`builtins` no longer holds `fetchTree`, `fetchClosure` or `outputOf`, so `builtins ? fetchTree` is `false` and `builtins.fetchTree` fails as a missing attribute, as under upstream's default settings, where it was a function that failed when called.** Upstream registers the three only with an experimental feature on (`fetch-tree`, `fetch-closure` and `dynamic-derivations`; `primop_fetchTree` in fetchTree.cc, `primop_fetchClosure` in fetchClosure.cc and `primop_outputOf` in primops.cc), and nova-nix has no experimental feature to turn on, so a program testing for one with `?` now takes the branch it takes under upstream. Their names are no longer interned with the base environment either, where they took their place ahead of a program's own names.

- **A derivation is fixed-output whenever its `outputHash` is set, an empty one or one that is not a string included, a fixed output's outputs must be `out` alone, and an empty hash, in `outputHash` or in the `sha256` of `builtins.fetchurl`, `builtins.fetchTarball` and `builtins.path`, is the all-zero hash upstream warns of.** `derivationStrict` took an empty `outputHash`, and one that was not a string, as absent, so `outputHash = ""` and `outputHash = 5` made an input-addressed derivation, and it wrote a fixed-output `.drv` with the one output `out` whatever `outputs` listed, so `.dev` of one with `outputs = [ "out" "dev" ]` was a missing attribute. Upstream reads `outputHash` in its pass over the attributes, coerced as every environment entry is, or as a string under `__structuredAttrs` (primops.cc:1317-1318, 1351 at 2.24.9), takes the derivation as fixed-output once it is set, refuses any outputs but `out` with `multiple outputs are not supported in fixed-output derivations`, and reads the hash with `newHashAllowEmpty` (primops.cc:1425-1435): an empty hash is the hash of `outputHashAlgo`'s algorithm whose every byte is zero, with `warning: found empty hash, assuming 'sha256-AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA='` on stderr, and is refused with `empty hash requires explicit hash algorithm` when `outputHashAlgo` names no algorithm upstream knows (hash.cc:271-281). nova-nix now does the same, so `outputHash = 5` fails with `hash '5' has wrong length for hash algorithm 'sha256'` given that algorithm and with `hash '5' does not include a type, nor is the type otherwise known from context` given none, and `outputHash = null` is the empty hash unless `__ignoreNulls` leaves it out. `outputHashMode` is read as before: `recursive` gives a recursive hash and every other value a flat one.

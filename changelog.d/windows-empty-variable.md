- **On Windows a variable set to nothing counts as set, as upstream reads it, so an empty `NO_COLOR` turns colour off there as it does elsewhere.** A Windows variable was read through base's `lookupEnv`, which reads a value of no characters as unset. nova-nix now asks `GetEnvironmentVariableW` for the space the value needs first, as upstream does, which is none only for a variable that is not set, so every variable nova-nix reads, `NO_COLOR` and `NIX_STATE_HOME` among them, is set when it is set to nothing.

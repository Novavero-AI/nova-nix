- **A substituted path whose narinfo states a content address is held to it, as upstream holds one: once its NAR's hash and size are checked, the tree is hashed as the address's method reads it, modulo the path's hash part, and a tree that hashes otherwise is removed and refused with upstream's `ca hash mismatch importing path '...'`, both hashes after it.** nova-nix checked a substitute against its narinfo's NarHash and NarSize alone. Upstream's `LocalStore::addToStore` (local-store.cc, the same at 2.24.9, 2.34.9 and 2.36.0) also checks a narinfo's `CA`: a `fixed:r:` address is of the tree's NAR, and a `fixed:` or `text:` address of the bytes of the one file it names, each hashed under the address's algorithm with every occurrence of the path's hash part counted as zeros and the offset of each appended, so a tree that refers to itself does not hash as one with zeros in its place. A narinfo that states no address is still held to its NarHash alone, as upstream's is, so a fixed output a cache supplies without one is not held to its recipe's hash, and `trust`'s reference now says so.
- **Library API:** `Nix.Hash` exports `ModuloHash`, `moduloHashInit`, `moduloHashUpdate` and `moduloHashFinalize`, a digest modulo a hash part; `Nix.Daemon.Protocol` exports `parseContentAddress`; and `Nix.Substituter` exports `checkStatedAddress`.

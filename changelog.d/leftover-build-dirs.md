- **A build directory, or a sandbox's chroot, that an earlier build left and that cannot be removed is moved aside, with a warning, and the build goes on.** Both are named by the derivation, so a leftover that cannot be removed, such as a directory another user made there through a descriptor a fixed-output builder handed out, which the user may neither empty nor change, failed every later build of the derivation. It now moves to the first free name of its path with `.leftover.` and a number after it, beside it in the store's state directory, and the warning names both paths. Removal that runs out of descriptors on a tree deep enough leaves a chroot the next build moves aside the same way.
- **Library API:** `Nix.Builder.BuildDir` exports `clearLeftover`, which removes what an earlier build left at a path or moves it aside.

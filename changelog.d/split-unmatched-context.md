- **`builtins.split` of a string its regex does not match gives back the string with its context, as upstream's does.** It rebuilt the string without context, so `builtins.hasContext (builtins.head (builtins.split "x" s))` was false for a string `s` with context; upstream returns the argument value itself there (`prim_split` in primops.cc). The pieces of a string the regex matches carry no context under either.

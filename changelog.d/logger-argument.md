- **Library API:** library code reports through a `Nix.Logger.Logger` it is given and never writes to standard error itself: a message (a wait on a lock, a collection's progress, a substitution's or a push's progress, a warning, a trace) and each line a builder writes, as the line completes and unfiltered. `openStore` takes the logger the store's operations report through, which the handle holds as `stLogger`, and a build, a substitution, a collection and a push report through their store's. `withLocalStore`, `newEvalStateWith`, `readProfileEnvironment`, `updateProfile`, `ioRetryEffects`, `queryReferencesWith`, `queryNextOfferWith`, `realiseWithoutWriting`, `withBuildDir`, `clearLeftover`, `runBuiltinBuildenv`, `warnFallback`, `runHelper`, `withChroot`, `streamBuildLog`, Push's `logSkipped`, `logNar` and `logPushed`, and the lock functions of `Nix.Store.Lock` take one, whose busy messages are `Text`, as `findingRootsMessage` is. `SessionSettings` holds one as `sessionLogger`, and `BuildConfig` no longer has `bcBuildLog`. `handleLogger` writes each report to a handle, a build line filtered for the terminal by `filterLogLine` under `escapeFilterFor`, which move to `Nix.Logger` from `Nix.Builder.Log` with `EscapeFilter`. The command line's output is unchanged.

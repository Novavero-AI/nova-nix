- **The garbage collector quotes a root, a link or a target in double quotes, as upstream does from 2.35.4 on: `removing stale link from "<record>" to "<out-link>"`, `skipping invalid root from "<link>" to "<target>"`, `cannot read potential root "<path>"`, and the refusals `creating a garbage collector root ("<link>") in the Nix store is forbidden` and `cannot create symlink "<link>"; already exists`.** These lines quoted the path as upstream 2.24.9 does, in single quotes, or, inside the parentheses of the in-store refusal, not at all. Upstream 2.35.4 and 2.36.0 format these paths with `PathFmt`, which writes a path between double quotes and escapes nothing inside, and nova-nix follows the newest pinned release. `deleting '<path>'` and `Cannot delete path '<path>' since it is still alive` keep their single quotes, as upstream's do, since it formats those store paths as strings.

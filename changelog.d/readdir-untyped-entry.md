- **`builtins.readDir` lists a directory holding an entry it cannot stat, and only forcing that entry's value fails, as `builtins.readFileType` on it fails.** readDir stats every entry, so one entry whose stat the system refused failed the whole call, as it did for a directory that can be read but not searched, where every entry's stat is refused, and on Windows for a directory holding a file with a deny ACE, and for `C:/`. Upstream's `readDirectory` gives an entry whose `lstat` is refused with `EACCES` or `EPERM` no type (posix-source-accessor.cc:138-149 at 2.24.9), and `prim_readDir` binds such an entry to a deferred application of `builtins.readFileType` to its path under the directory with its symlinks resolved (primops.cc:2027-2051), so the listing names every entry and forcing one fails with readFileType's `getting status of '...': Permission denied`. readDir now does the same; any other failure to stat an entry still fails the listing, as upstream's does. `builtins.path` with a filter and `builtins.filterSource` read such an entry's type with an `lstat` of its own, as upstream's path filter does (primops.cc:2405-2424), so they fail on it as `readFileType` does, where they failed as the listing.
- **Library API:** `Nix.Eval.Types.MonadEval`'s `listDirectory` returns `[(Text, Maybe Text)]`, `Nothing` for an entry whose `lstat` is refused, where it returned `[(Text, Text)]`; an instance gives `Nothing` for such an entry, and a caller that needs every entry's type reads it with `getFileType`.

- **An output that records an already-valid sibling now builds, with the sibling's real path in its bytes.** A rebuild of a partly valid derivation writes the valid output to a scratch path, and an output that recorded that path used to fail the build, because the scratch tree is discarded. Upstream rewrites the scratch hash to the final one in the output (`rewriteOutput` at 2.24.9) and the build succeeds. The hash is now rewritten across file contents, symlink targets and entry names, so the output names its sibling and records the reference. Upstream scans and then rewrites, and this rewrites and then scans, which finds the same references with no translation. Upstream's rewrite runs over a serialized NAR, so a rename that changes a directory's sort order fails there, depending on the hash values, and succeeds here. Reference scanning also now covers entry names, as upstream's scan of the NAR does, so a hash held only in a file name records its reference.
- **Library API:** `Nix.Store.scanTempReferences` is removed, and `rewriteStoreHashes` and `rewriteBytes` are added.

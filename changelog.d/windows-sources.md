- **Every package in `pkgs/windows` states the sources it fetches in `srcs`, and `pkgs/windows/sources.nix` lists them all.** A package names its sources inside its build script, where a walk over attributes such as nixpkgs' `find-tarballs.nix` does not find them, so nothing could fetch a package's sources without building it. CI realises the list from the public cache before each job builds, and a push to main publishes it there, so a source is fetched from its upstream host when the change that brings it is tested and merged, and not on every run. A job fails if the cache cannot be asked, where falling back would send its downloads to the upstream hosts. The test suite checks the list against the fetches in the closure of every derivation in the set.

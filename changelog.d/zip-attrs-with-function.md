- **`builtins.zipAttrsWith` refuses a first argument that is not a function before it forces the list, as upstream's does, so `builtins.zipAttrsWith 1 [ ]` fails with `expected a function but found an integer: 1` where it gave `{ }`.** It never checked its function: given sets, it built a set of applications of the `1` that failed only when one was forced, so `builtins.attrNames (builtins.zipAttrsWith 1 [ { a = 1; } ])` was `[ "a" ]`, and it forced the list as it was applied, so `builtins.zipAttrsWith 1 (throw "b")` failed with `b`. Upstream's `prim_zipAttrsWith` forces its first argument with `forceFunction`, which takes a lambda, a builtin or a set with `__functor`, and only then forces the list (primops.cc:3145-3146 and eval.cc:2202-2216 at 2.24.9), so the function fails first whatever the list holds, and nova-nix now does the same.

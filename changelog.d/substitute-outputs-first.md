- **`build --substituter` tries a derivation's outputs before its inputs, and a substituted path arrives with its runtime closure.** Dependencies used to be walked leaves first, so every build-time input was fetched or built before the root's own outputs were tried: `pkgsCross.mingwW64.hello`, one 0.19 MB path on cache.nixos.org, pulled more than 4 GB across 2,600 paths. Upstream tries outputs first (`DerivationGoal::haveDerivation` at 2.24.9) and only then falls back to inputs, so a derivation the cache holds now takes its inputs out of the work. A narinfo's references are realised before the path that names them, as upstream's `PathSubstitutionGoal` does, after the narinfo passes the same identity and signature checks as a substitution, so the store stays closed under references. A reference no cache holds leaves that substitution incomplete, so the inputs are realised, and when they supply the hole the substitution is retried once, matching upstream's `retrySubstitution`; otherwise the derivation builds.
- **Library API:** The new module `Nix.Realise` decides what a build substitutes and what it builds, root first: `substituteClosure` over the effects in `SubstEffects`, and `realise` over those in `RealiseEffects`. `Nix.Builder` exports `substitutePaths`, and `Nix.Substituter` exports `queryReferencesWith`.

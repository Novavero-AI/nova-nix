- **`nova-nix build` realises only the output it prints, the one the derivation's `outputName` names, as `nix-build` does, so with that output valid it builds and downloads nothing, whatever the state of the derivation's other outputs.** `nix-build` asks for each derivation's `outputName` alone (`main_nix_build` in nix-build.cc, the same at 2.24.9, 2.34.9 and 2.36.0); nova-nix asked for every output, so a missing sibling output, such as a `dev` a collection deleted, was downloaded or built again. A build the requested output needs still builds every output of the derivation, as upstream's does. `--check` still checks every output.

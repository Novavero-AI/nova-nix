- **A store path's info records whether this store built it, the signatures it came with and the content address its name was made from, and the store lists each valid derivation's outputs, in the columns and the table upstream's database has.** A built output is ultimately trusted, and a fixed one has the address it was checked against; a substituted path keeps its narinfo's signatures and the address its tree was held to; a source, a write evaluation made and a `.drv` have the address their paths are made from. Upstream records the same (`ultimate`, `sigs` and `ca` in `ValidPaths`, and `DerivationOutputs`), and a daemon answering for the store reads them back. A database an earlier nova-nix made gains the columns, empty in every row it holds, and the table, filled from the derivations it holds, the first time it is opened for writing.
- **Registering a path whose name ends in `.drv` reads it as a derivation, and one that does not parse is refused with `error parsing derivation '...'`, as upstream's store refuses it.** Upstream lists a derivation's outputs from its file when it registers it, so a `.drv` that is not a derivation never becomes valid there.
- **A garbage collector root for an out-link whose name has no UTF-8 reading keeps that name: the link is made, recorded and found again under the bytes it was given.** The link's spelling went through text, which replaced each such byte with U+FFFD, so the link was made under a name other than the one asked for, and its record held that name. Upstream keeps a root's path as bytes.
- **Library API:** `PathRegistration` has `prUltimate`, `prSignatures` and `prContentAddress`, and `PathInfo` has `piUltimate`, `piSignatures` and `piContentAddress`, with the new `Ultimate` type. `Nix.Store.DB` has `queryReferrers`, `queryValidDerivers` and `queryPathFromHashPart`. `checkStatedAddress` answers the content address it held the tree to. `indirectRootRecordName` takes the bytes of the link's spelling. `absolutePath` is defined in `Nix.HostPath`, and `Nix.Profile.Generation` still exports it. `Nix.Daemon.Protocol` exports `parseSignature`, `renderSignature` and `renderContentAddress`, and `Nix.Derivation` exports `drvExtension`.

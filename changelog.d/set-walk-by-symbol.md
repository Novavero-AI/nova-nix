- **`builtins.deepSeq` and `nova-nix eval --strict` force a set's values in the order the set holds them, by the symbols of their names, as upstream's do: `builtins.deepSeq { zb = throw "b"; za = throw "a"; } null` fails with `b`, where it failed with `a`. `mapAttrs`, `zipAttrsWith`, `intersectAttrs`, `builtins.path` and `scopedImport` read a set by those symbols too, and allocate less.** Upstream's `forceValueDeep` forces a set's values as it walks the set's `Bindings` (eval.cc), which are sorted by `Symbol`, the order the symbol table interned each name in (`Attr::operator<=>` in attr-set.hh, `Symbol::operator<=>` in symbol-table.hh). nova-nix forced them in the order of the names' text, so of two values that fail, the one whose name sorts first failed, where under upstream the one whose name was interned first does; the order decides only which failure wins. The builtins copied a whole set into a map keyed by each name's text and interned every name back into the symbol the set already held it under. Each now walks the set's own array, sorted by symbol, one entry at a time, and turns a name into text only where it is read as text. `intersectAttrs` walks the smaller of its sets and finds each name in the other, as upstream's does (`prim_intersectAttrs` in primops.cc), and `scopedImport` binds its scope's names by the scope set itself, as upstream binds the set's own values in the environment it evaluates the file in (`import` in primops.cc), where nova-nix copied them into a new set. On `profiling/stress.nix`, whose one `mapAttrs` maps 10,000 names, evaluation allocates 1.337 GB where it allocated 1.350 GB.
- **Library API:** `Nix.Eval.Types.attrSetMapWithKey` passes each name to its action as a `Symbol` where it passed `Text`. `MonadEval`'s `scopedImportFile` takes the scope as an `AttrSet` where it took a list of names and values, and `Nix.Builtins.builtinEnvWithScope` takes that set, which becomes the environment's name table, in place of the list. `Nix.Eval.Types` exports `attrSetFoldM`, which folds an action over a set's attributes in the order the set holds them, and `attrSetLookupSymbolEntry`, which looks an attribute up with its position by the `Symbol` of its name.

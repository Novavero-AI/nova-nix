- **A chain of `//` merges its operands from the first, as upstream 2.34's update queue does: `a // b // c` layers `b` on `a` and then `c` on that, where it made `b // c` first and merged `a` with it.** `//` groups to the right, so a chain parses as `a // (b // c)`. Upstream 2.34 gathers a chain's operands, descending only into an operand that is itself an update, and once it has evaluated them all folds them into one set from the leftmost (`ExprOpUpdate::eval` and `ExprOpUpdate::evalForUpdate` in eval.cc), so a chain of small sets on a large one copies the small ones alone, once each. A chain one of whose operands fails merges none.

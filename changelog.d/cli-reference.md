- **`nova-nix --help` lists each flag under the commands that take it, and each nix.conf setting with what it does, printed from one reference of the CLI that `docs/cli.json` also renders.** The help named the command for some flags and not for others, so `--strict`, which `build` refuses, read as a flag of every command. Two entries said what the code does not do: `--trusted-key` was the key for the substituter, but a trusted key is checked against the signatures of every substituter, those nix.conf configures included; and `--pure-eval` left no search path, but the bundled `<nix/*>` expressions stay on it, as upstream still resolves `<nix/*>` from its built-in copy. `--expr` and `--cache`, which appeared only in the command lines, have entries of their own; `push` has a line for `PATH...` and one for `--all`, one of which it requires; the usage line is `nova-nix COMMAND [FLAG...]`, where it named `--nix-path` alone of the flags that may come before a command; the system nix.conf directory is given for both platforms; and the text wraps at 80 columns. The test suite checks the reference against the parser, that every command it lists for a flag accepts the flag and that a flag takes a value exactly when its entry names one, and runs each example that shows its output.

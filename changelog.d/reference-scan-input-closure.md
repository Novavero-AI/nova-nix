- **A build records a reference to any path in its inputs' closure that an output embeds, not only to its direct inputs.** Reference scanning looked for the input sources, the input derivations' outputs and their `.drv` files, so an output embedding a path an input only references, such as a library the input propagates, registered without that reference. A garbage collection could then delete a path a live output still used, and a pushed closure could lack it. Upstream scans for its `inputPaths`, the closures of the requested input outputs and of the input sources under their registered references (`derivation-goal.cc` at 2.24.9), plus the derivation's own outputs (`referenceablePaths` in `local-derivation-goal.cc`), and the scan now uses that set. An input derivation's `.drv` is not in it, so an output that embeds one no longer records it, as upstream's does not; a `.drv` an input source reaches, as one a `drvPath`'s context brings in, still is.
- **Library API:** `Nix.Builder` exports `closureUnder`, the closure of a list of roots under a references lookup in any monad.

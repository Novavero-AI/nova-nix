- **`allow-import-from-derivation` and `trace-import-from-derivation` are read from `nix.conf` and `NIX_CONFIG`, and `--no-allow-import-from-derivation` turns the first off for one run of `eval`, `build` or `trust`.** With it off, a builtin that reads a path whose context names a derivation's output fails with upstream's `cannot build '<drv>^<output>' during evaluation because the option 'allow-import-from-derivation' is disabled`, naming the first output in upstream's order, once every path the context names is valid and before anything is added or built, so an output already valid is refused too (`EvalState::realiseContext` in primops.cc); `builtins.tryEval` does not catch it, as upstream's catches only an assertion, and a read-only `eval` refuses as a `build` does. With `trace-import-from-derivation` on, each such read warns `built '<drv>^<output>' during evaluation due to an import from derivation` before it builds anything, as 2.34.9 does (`EvalState::realiseContext` in primops.cc); the warning has no effect with the first setting off, as upstream's has none. There is no `--allow-import-from-derivation`: as for every setting, a flag only moves the setting from its default, so a machine configured to refuse an import from derivation keeps refusing it whatever the command line says.
- **Library API:** `Nix.Eval.Policy.EvalPolicy` gains `epImportFromDerivation`, an `ImportFromDerivation` that is `RefuseImportFromDerivation`, `AllowImportFromDerivation` (in `unrestrictedPolicy`) or `TraceImportFromDerivation`. `Nix.Eval.RealiseContext.planRealisation` takes one first, `Plan` gains `planWarning`, and `ContextRefusal` gains `ImportFromDerivationOff`. `Nix.Config.NixConfig` gains `ncAllowImportFromDerivation` and `ncTraceImportFromDerivation`, and `Nix.Eval.Types` exports `warnMessage`, upstream's `warn`.

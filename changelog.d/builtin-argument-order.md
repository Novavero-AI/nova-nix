- **Ten builtins force the argument their primop forces late where the primop forces it, so `map (throw "a") [ ]` is `[ ]`, and when two arguments throw, the error is the one upstream reports.** A builtin's arguments were forced as they were applied, left to right, so `map`, `filter`, `sort`, `mapAttrs` and `elem` failed on an empty collection whose function or needle throws, where upstream succeeds, and with both arguments throwing the first one's error was reported where upstream reports the second's. Upstream's `prim_map`, `prim_filter` and `prim_sort` force the list and return an empty one before they force the function; `prim_mapAttrs` never forces the function itself, so `mapAttrs (throw "a") { x = 1; }` has the attribute `x`; `prim_elem` forces the needle only to compare it with an element; `prim_elemAt` and `prim_genList` force their second argument first; `prim_foldlStrict` hands its initial accumulator to the first step unforced and forces it itself only for an empty list; and `prim_filterSource` and `scopedImport` coerce the path before they force the filter or the scope (primops.cc at 2.24.9). Each of these builtins now takes that argument unforced and forces it at the same point, in a partial application too, so `builtins.typeOf (map (throw "a"))` is `"lambda"`. A function argument forced there is checked as upstream's `forceFunction` checks it, so `builtins.length (map 1 [ 1 ])` fails with `expected a function but found an integer: 1`, where it returned 1. Any other argument is still forced as it is applied, where upstream forces nothing before a primop has all its arguments, so a partial application such as `builtins.foldl' (throw "a")` still fails when forced.
- **Library API:** `VBuiltin` holds the arguments a builtin has taken as `BuiltinArg`, `ArgForced` or `ArgDeferred`, where it held values. The registry's `BuiltinDef` gives a builtin's argument modes as `bdArgs :: NonEmpty ArgMode`, where it gave `bdArity`, and `bdApply` takes `[BuiltinArg]`. `Nix.Eval` exports `BuiltinArg (..)` and `ArgMode (..)`.

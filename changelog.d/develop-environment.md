- **Library API:** `Nix.Develop.Environment` holds the build environment upstream's `nix develop` captures and the scripts made from it, as upstream's `BuildEnvironment`, `makeRcScript` and `CmdDevelop::run` make them (develop.cc at 2.35.4). `parseBuildEnvironment` reads the JSON `get-env.sh` writes, dropping a variable of a kind it does not know as upstream does, and `buildEnvironmentJson` writes it back. `environmentScript` gives the script `print-dev-env` prints, each output's path moved under the working directory, with the structured attributes' files to write; `renderRcfile` wraps it for an interactive shell, `--command` or `--phase`. `ignoreVars` and `escapeShellArgAlways` are upstream's. Where upstream asserts that a variable is set, or replaces a path forever because the text replacing it holds it, these return an error.

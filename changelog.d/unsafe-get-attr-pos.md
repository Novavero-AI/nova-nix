- **`builtins.unsafeGetAttrPos` gives the position an attribute was defined at, `{ column; file; line; }` for one defined in a file, where it gave `null` for every attribute.** Upstream answers with `EvalState::mkPos` of the attribute's position (`prim_unsafeGetAttrPos`, primops.cc at 2.24.9), and its positions are matched: a binding is at the first token of its attribute path, every level of a dotted `a.b.c = v;` at the path's, and an inherited name at the name, as upstream's parser records them (parser.y, parser-state.hh); a binding merged into an earlier path keeps its own position and the path its first; `//`, `removeAttrs` and `intersectAttrs` keep the positions of the attributes they copy, `listToAttrs` puts each attribute at its element's `value`, and every other set a builtin makes, `mapAttrs`'s included, has none. A missing attribute, one with no position and one defined in an `--expr` argument give `null`, as upstream's do for text with no file behind it. The name is checked before the set is forced, as upstream's `forceStringNoCtx` of it runs first. nixpkgs reads the position for `meta.position`. A derivation's own attributes report the lines of the `derivation` wrapper in `/derivation-internal.nix`, which differ from upstream's. Columns count characters where upstream's count bytes, so they differ on a line with non-ASCII text before the attribute; they follow the lexer, whose parse errors count the same way. The `file` is the path the import read, every symlink on it resolved, where upstream keeps the path as written and follows only a symlink at its end (`resolveExprPath`, eval.cc), so the two differ for a file reached through a symlinked directory. `builtins.functionArgs` gives its attributes no position, where upstream gives each formal's.
- **Library API:** `Nix.Parser.parseNix` and `parseNixWithScope` take a `SourceOrigin` (`SourceFile` or `SourceText`, from `Nix.Expr.Types`) where they took the name errors give the source, and `Nix.Parser.Internal.ParseState` holds it as `psOrigin` where it held `psFile`. `NamedBinding` and `Inherit` carry the `SrcPos` they were parsed at, and `InheritFrom` holds `InheritedName`s, each with its own; `Nix.Eval.Compile`'s `BcNamed`, `BcInherit` and `BcInheritedName` carry the `PosIdx` they were recorded at. `Nix.Eval.CAttrSet.cattrsetInsert` takes the entry's `PosIdx`, which `cattrsetGetPos` reads back; the new `Nix.Eval.SourcePos` records positions and reads them back, and `Nix.Eval.Types` gains `AttrEntry`, `attrSetLookupEntry` and `attrSetFromEntries`.

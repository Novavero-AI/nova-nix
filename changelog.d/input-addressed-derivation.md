- **Library API:** `Nix.Derivation` exports `inputAddressed`, which makes every output of a derivation input-addressed from the derivation's name and its inputs' modulo hashes and gives the `.drv` file it is written as, as upstream's `fillInOutputPaths` and `writeDerivation` do (derivations.cc), and `drvFile`, the `.drv` file of a derivation as it stands. A `DrvFile` holds the derivation, its ATerm and its store path (`drvFileDerivation`, `drvFileATerm`, `drvFilePath`). `derivationStrict` fills in an input-addressed derivation through `inputAddressed`, and every drvPath and output path is the one it gave before. `Nix.Eval.Types.storePathOrThrow` unwraps the result of any construction that makes a store path, not only a store path itself.

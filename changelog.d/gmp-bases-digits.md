- **`gcc-core` and `gcc46-cxx` build gmp's table of digits per bit from fixed digits, so `gcc46-cxx` builds to the same bytes on x64 and ARM64 Windows.** gmp writes the table at build time with a program it compiles and runs on the build machine, which computed each base's value with that machine's `log` and `printf`. Under ARM64 Windows' x86 emulator, which carries out x87 arithmetic in double precision, `gcc46-cxx`'s program wrote other last digits for 13 of the 255 bases, so the rung's `cc1` and `cc1plus` differed between the two legs of the ladder. A patch to gmp's generator has it write fixed digits instead, those an x86 processor gives, which are the table both rungs wrote on x64 before: each base's value is 0.69314718055994530942 divided by `log(base)` in double precision, the log and the quotient each rounded to the nearest double, written to sixteen places from its first seventeen significant digits. The later gmp that GCC 10 and GCC 16 build computes its table in integers, and needs no patch.

- **`nova-nix build` links its output from `./result` and makes the link a root the garbage collector keeps, as `nix-build` does, and `--no-out-link`, or its other spelling `--no-link`, links nothing.** It linked nothing unless `--out-link` was given. The link is named as nix-build names it (nix-build.cc:701-720 at 2.24.9): `./result`, or the path `--out-link` gives, for the output `out`, and that path with `-NAME` appended for any other output, so `-A dev` links `./result-dev`. nix-build's `-2`, `-3` and so on for a second and later derivation do not arise, since `build` builds one. The link is made and registered as an `--out-link` was, by upstream's `addPermRoot` rules: a link already there that points into the store is replaced, and anything else at the path fails the command after the build, with no path printed. A build that fails, or a check that finds an output different, links nothing, since upstream's `Store::buildPaths` throws before nix-build links (nix-build.cc:695, build/entry-points.cc:41-46). nix-build's `--no-out-link` links into a temporary directory it deletes on exit (nix-build.cc:143 and 203-204), which leaves a dangling record that its next collection removes with a `removing stale link` line (gc.cc:246-249); here nothing is linked or recorded, which leaves the store as upstream leaves it, less that record. Of several link flags on one command line the later wins, as nix-build's does, since it sets its link as it reads each flag (nix-build.cc:203-204 and 212-213): `-o a --no-out-link` links nothing, `--no-out-link -o a` links `a`, and `-o a -o b` links `b`, where a second `--out-link` was refused. A script that runs `build` now leaves `./result` in its working directory, and since a link into another store is replaced only when that store is the platform store, a script that builds into two scratch stores from one directory fails at the second build's link; `--no-out-link` keeps such a script as it was. On Windows the link is a symlink, which needs Developer Mode or an elevated shell, so without either a build fails at its link unless `--no-out-link` is given.

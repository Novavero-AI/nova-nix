- **Library API:** `Nix.Eval.Types` has `attrSetFindName`, which walks a set in order and stops at the first name a test holds for, and `attrSetAllPairs`, which walks two sets in lockstep and stops at the first pair an action fails. `Nix.Eval.CAttrSet` drops `cattrsetKeys`, `cattrsetGetKey`, `cattrsetGetPos` and `cattrsetGetValue`: a set is walked in symbol order with the new `cattrsetWalk` and `cattrsetWalkNext`, a `CAttrSetStep` at a time, and read by name with the new `cattrsetFind`, which gives an entry's position and value and finds a value not yet written, and `cattrsetMember`. `cattrsetIndex` and `cattrsetSetValue` take a `FlatCAttrSet`, the name table `cattrsetFromNames` makes, whose set `flatCAttrSet` gives; `buildCAttrSetKeys` gives one and `fillCAttrSetValues` takes one.

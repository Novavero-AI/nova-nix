- **`pkgs/windows`' Mes is GNU Mes 0.28, with the Windows port merged onto upstream's master.** 0.28 replaces Mes's tree-walking interpreter with a bytecode compiler and interpreter. Mes and MesCC run in the arena and stack MesCC's own script sets, 20,000,000 cells and 60,000 entries: 0.28 asserts that the stack stays under 131,072 entries, where `pkgs/windows` set 6,000,000, and reads no `MES_MAX_ARENA`. A collection copies the cells it keeps into the arena's free third and stops Mes with an out-of-memory error when they do not fit, where 0.27.1 copied them past the arena's end without checking, so the first TinyCC round runs in Mes's own arena rather than a doubled one, and CI no longer measures the cells Mes keeps. Upstream fixes `strpbrk` itself, so the fork carries nixpkgs' other i686 C library fixes alone.

- **Library API:** `Nix.Builder.attrsDelivery` takes the build directory and outputs where the builder sees them, and the `adFiles` of the `AttrsDelivery` it gives name each file in the build directory, where they held its path there. `Nix.Builder` exports `BuildPlace`, a path as the builder is told of it and on disk, `BuildLayout`, a build's directory and outputs as places, and `builderInvocation`, which gives the `BuilderInvocation` a spawned builder starts with: the program and arguments, the environment and the ambient variables copied into it, the files written before it starts and the directory it starts in.

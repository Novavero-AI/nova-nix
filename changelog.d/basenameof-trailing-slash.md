- **`builtins.baseNameOf` drops a single trailing `/` from a string, as upstream does, so `baseNameOf "a//"` is `""` where it was `"a"`.** Upstream's `legacyBaseNameOf` (primops.cc, the same at 2.24.9, 2.34.9 and 2.36.0) removes one final slash, unless it is the whole string, and returns what follows the last slash before it; nova-nix dropped every trailing slash and every empty component. `baseNameOf "a/"` is still `"a"`, and a path value is unchanged.

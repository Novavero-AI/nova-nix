- **A keyword other than `or` is no attribute name, as upstream refuses it, so `{ if = 1; }`, `x.then` and `inherit rec;` are syntax errors at the keyword, where they named an attribute `if`, `then` or `rec`.** Upstream's grammar takes an attribute name, in a binding, a selection, a has-attribute test or an `inherit`, as an identifier or `or` (the `attr` rule, parser.y:455-458 at 2.24.9), and its lexer makes `if`, `then`, `else`, `assert`, `with`, `let`, `in`, `rec` and `inherit` tokens of their own (lexer.l:109-117), so an attribute named like one is written as a string there, `{ "if" = 1; }` and `x."then"`, as it now must be here. `true`, `false` and `null`, which upstream's lexer reads as identifiers, stay attribute names.

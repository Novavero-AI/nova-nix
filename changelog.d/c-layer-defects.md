- **A closure or string context element holding a tag the C side does not name raises `CInvariantViolated`, where it was read as a set pattern with a name or as a whole derivation's outputs.** A lambda's formals type and a context element's tag are read against the constants the C side names (`NN_FORMALS_*`, `NN_SCE_*`), so memory written past the library is reported with the site that read it rather than evaluated as another value. A with-scope count at its limit, which only corrupt state reaches, aborts at the check that names it, where it was reported as an allocation failure, so a C allocator's NULL means only that it could not allocate.
- **Library API:** `Nix.Eval.CThunk` no longer exports `cthunkGetStr`, `cthunkGetPath`, `cthunkGetList`, `cthunkGetAttrs`, `cthunkGetCtxStr` and `cthunkGetLambda`, each of which answered the payload `cthunkPayload` answers, which a caller casts. `Nix.Eval.CEnv` renames `cenvLazyScope` to `cenvNameTable`, the set of names an environment binds. `cenvLookupResolved` takes `Word32` coordinates and raises `CInvariantViolated` where it answered `nullPtr`, and `Nix.Eval.Types.envLookupResolved` takes `Word32` coordinates. `Nix.Eval.CEnv`'s `cenvNew` and `cenvPushWith`, `Nix.Eval.CLambda.clambdaNew` and `Nix.Eval.CCtxStr.cctxstrNew` raise a `CStatusError` where they answered `nullPtr`. `Nix.Eval.CLambda` exports `FormalsName`, `FormalsSet` and `FormalsNamedSet`, and `Nix.Eval.CCtxStr` exports `ScePlain`, `SceDrvOutput` and `SceAllOutputs`, the tags their C structs hold.

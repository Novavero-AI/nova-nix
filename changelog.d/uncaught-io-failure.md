- **An I/O failure no command handles prints `error:` and its message and exits 1, as upstream's do, where it printed GHC's `Uncaught exception` report with a backtrace.** The store's refusal of an unregistered reference, for one, printed `nova-nix: Uncaught exception ghc-internal:GHC.Internal.IO.Exception.IOException:`, its message inside `user error (...)`, and a `HasCallStack backtrace`. Upstream's `handleExceptions` (libmain/shared.cc at 2.24.9) logs any error as one `error:` line and exits 1, and the CLI now does the same for an `IOException`: a `userError` prints its message, and any other also names the operation and the file that failed.

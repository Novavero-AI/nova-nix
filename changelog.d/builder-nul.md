- **A builder's program, arguments and environment entries end at their first NUL, as upstream's exec takes them.** Upstream passes each argument and each `NAME=VALUE` entry it builds to `execve` as a C string (`stringsToCharPtrs`, util.cc:44-50 at 2.24.9, and local-derivation-goal.cc:2000-2004 and 2231), so its builder gets each up to the first NUL a derivation's string holds, which `builtins.fromJSON` can put there. nova-nix refused to spawn a builder whose environment held a NUL, since the process library refuses one, and on Windows a NUL in a value started another variable and one in an argument ended the command line. Each is now cut at its first NUL before the spawn, so the builder gets what upstream's gets, with one exception: an entry left with no `=`, by a name holding a NUL, is one the process library cannot pass, and is left out. Upstream passes it, and no `getenv` finds a variable in it.

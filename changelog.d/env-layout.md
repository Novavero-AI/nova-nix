- **Environments take less than half the memory they did: a call's environment of one value takes 24 bytes where it took 56, and one with no parent, a trimmed closure's or a builtin's deferred application, takes 8 bytes and 8 per value.** An environment was a 48-byte struct in front of a separate array of its values, with room in every one for a lazy scope and with-scopes that only a `with`, a root environment and a frame whose names are not all static use, and over a nixpkgs slice environments took nearly five times upstream's bytes (#529). Upstream's `Env` is a parent pointer and its values (eval.hh:135-139 at 2.24.9). An environment is now one word holding its value count and which fields follow, its values inline, then its parent when it has one and its lazy scope and with-scopes when it has them, so everything it points to is found from the environment alone. An environment sees the with-scopes of the nearest environment on its parent chain that has its own, a `with`'s or a trimmed closure's, where each environment carried a copy of its parent's; a `with`'s environment copies the values of the one it is made in, and the census's counts by site and by size count them with it. On `fib 25` and `profiling/stress.nix` the environments' bytes fall from 13.6 and 40.6 MB to 5.8 and 18.5 MB, and peak memory on `fib 30` from 223 to 132 MiB; wall time is unchanged within run-to-run noise. What any program evaluates to is unchanged.
- **Library API:** in `Nix.Eval.Types`, `newEnv`, which takes a site, a parent or none and the thunks for the slots, and `newScopeEnv`, which takes a site, a parent or none and a lazy scope, replace `buildCSlots`, `newMinimalEnv`, `envFromSlots` and `newCEnv`, and `tieFrame` takes a site, the frame's parent and its slot count where it took a site, a slot count and a function building the environment over a slot array. In `Nix.Eval.CEnv`, `cenvNew` takes a site, a slot count and a parent, `cenvNewScoped` and `cenvWithOwner` are new, `cenvSlots` answers the environment's own slots, `cenvWithScopes` and `cenvWithCount` read the with-scopes an environment has of its own (`envWithScopesRaw` answers those it sees), and `cenvAllocSlots`, `cenvFromSlots` and `cenvNewMinimal` are removed.

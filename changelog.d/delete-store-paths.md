- **`deleteStorePaths` replaces `withLiveSet` and `deleteStorePathChecked`, so a delete's live set cannot outlive its collector lock or come from another store.** `withLiveSet` handed its callback a `LiveSet` the callback could return, and `deleteStorePathChecked` took the live set and the store separately, so a library caller could delete with a live set after the collector lock was released, or with another store's: the liveness check then read the roots as they stood when the set was made, or another store's roots, and the delete removed a live path. The live set is now made and consumed inside one call. `store delete` runs on `deleteStorePaths` and prints what it printed.
- **Library API:** `Nix.Store.GC` adds `deleteStorePaths :: Store -> [Text] -> (Text -> DeleteOutcome -> IO ()) -> IO (Either Text ())`, which deletes the named basenames in order under one collector lock and one live set, runs the action after each deletion, and stops at the first refusal, which it returns; it refuses whatever `deleteStorePathRaw` refuses. `LiveSet`, `withLiveSet` and `isLive` are removed from `Nix.Store.GC`, and `deleteStorePathChecked` from `Nix.Store`: a batch delete calls `deleteStorePaths`. `DeleteOutcome` and `deleteStorePathRaw` move from `Nix.Store` to `Nix.Store.GC`, which `Nix.Store` re-exports, so an import from `Nix.Store` is unchanged.

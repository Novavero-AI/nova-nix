- **A builtin's deferred application of a function, one per element of `map`, `genList`, `mapAttrs` and `zipAttrsWith`, holds the function's and the arguments' cells and no environment, as upstream's is an app value: 16 bytes where it took 24, and 24 for a name and a value where it took 32; `concatMap` calls its function on each element and defers nothing.** Over the first 2,000 attributes of nixpkgs 24.11 those builtins allocated 3.87 million environments of 109.3 MiB, a sixth of the environments' bytes, and upstream 2.24.9 allocates none of them: its `prim_map`, `prim_genList`, `prim_mapAttrs` and `prim_zipAttrsWith` make app values holding the function and its argument, and `prim_concatMap` calls `callFunction` on each element (primops.cc at 2.24.9). A pending thunk now holds either code and the environment it runs in, or such an application: the cells of its function and arguments in an array of the environment pages, which forcing it applies in a call frame of its own with the function forced inside it, as upstream's `forceValue` on an app value does, and with a second frame for the first of two arguments, as upstream's two nested app values have. So the call depth at which a callback is refused, the error it raises and what `tryEval` catches are unchanged. The census `NOVA_NIX_C_STATS` writes counts the arrays as a kind of their own (`apps.*`), which the memory report of `profiling/bench.sh` gives a row. On `profiling/stress.nix` environments take 9.8 MB where they took 15.2 MB, beside 3.6 MB of applications' cells; it runs 3% faster, and a sum over a `map` of a `genList` of 100,000 elements 13% faster, while `fib 30`, which makes no such application, runs about 2% slower. What any program evaluates to is unchanged.
- **Library API:** `Nix.Eval.Types.MonadEval`'s `forceThunk` takes the action that runs a `Pending`, a pending thunk's code in an environment (`PendingCode`) or its deferred application (`PendingApply`, `PendingApply2`), where it took one running code in an environment; `readPending` reads it from a cell, and `mkApplyThunk` and `mkApply2Thunk` make an application's cell. `Nix.Eval.CBytecode` loses `reservedApply1`, `reservedApply2`, `appDirect` and `appDeferred`: the bytecode store no longer opens with reserved instructions. `Nix.Eval.CThunk` gains `cthunkNewApply1`, `cthunkNewApply2`, `cthunkPendingForm`, `cthunkApplyCell` and `noCode`, the index of no instruction, which `cthunkGetBcIdx` answers for an application and `cthunkNewBc` refuses; `Nix.Eval.CStats.PerKind` has a `kindApps` field.

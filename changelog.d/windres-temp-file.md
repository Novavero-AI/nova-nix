- **The Windows stdenv's `windres`, and the GCC 16 rungs' builds, run windres' preprocessor without `cmd.exe`.** windres reads the output of the preprocessor it runs on a resource script through `popen`, which starts the command through `cmd.exe`, a program from outside the store; `--use-temp-file` has windres start the preprocessor itself and read its output from a file. The stdenv's `windres` wrapper passes it, as do `gcc-latest`, `gcc-core-x86_64`, `gcc-x86_64` and `gcc-native-x86_64`, which compile GCC's UTF-8 manifest with windres. Their `WINDRES` is in the derivation's environment rather than in `configureFlags`, which the seed stdenv splits at spaces, and configure takes a tool that is already set.

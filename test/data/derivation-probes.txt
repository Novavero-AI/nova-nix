#
#   argument  an argument for derivation
#   probe     an expression of `w` (derivation itself), `args` (an argument)
#             and `d` (w applied to args), evaluated for every argument
#   imported  a whole expression, evaluated from a file of its own
#
# The probes read the pattern and the name it binds, which builtin forces
# `outputs` and in what order, each attribute forced alone, the paths and
# their contexts, and equality between the output sets and with the
# arguments.  Upstream's `==` forces both sides before it takes one value
# as equal to itself, where nova-nix's takes a shared thunk as equal
# without forcing it; the equality probes show both.  Each leaves out the
# attributes that differ by design, so its result does not depend on the
# order attribute names were interned in.
#
# The first arguments cover one kind each.  The rest mix the same
# ingredients: names the wrapper defines or lists as outputs, values that
# throw or are functions, structured attributes, and an `outputs` that is
# absent, well formed or malformed.
